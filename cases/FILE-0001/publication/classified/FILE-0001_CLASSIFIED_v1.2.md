# FILE 01｜1947年、何が起きた？

まず、後年の宇宙船や遺体の話は置いておきます。

**1947年当時に残された記録だけ**を追います。

## 6月｜牧場で残骸が見つかる

マック・ブラゼルは、牧場で奇妙な残骸を発見したと1947年7月の新聞で証言しています。

```text
[ NEWSPAPER INSERT ]

Roswell Daily Record
1947年7月9日
マック・ブラゼルのインタビュー
```

彼が説明したのは、ゴム、薄い金属箔のような物、紙のような素材、棒、テープ、ハトメなどでした。

---

## 7月8日｜米軍が「空飛ぶ円盤を回収」と発表

```text
[ DOCUMENT / NEWSPAPER INSERT ]

Roswell Army Air Field
"Flying Disc" Announcement
1947年7月8日
```

ロズウェルの米軍基地は、実際に**「空飛ぶ円盤を回収した」**と発表しました。

これは後世の噂ではありません。

---

## 同じ日｜「気球」という説明も現れる

```text
[ DOCUMENT INSERT ]

FBI Teletype
1947年7月8日
```

同じ7月8日、FBIには軍から、回収物が**高高度気球とレーダー反射器に似ている**という説明が伝えられていました。

さらに軍側も、その後、気球とレーダー反射器という説明を示します。

```text
空飛ぶ円盤を回収
        ↓
気球・レーダー反射器
```

---

```text
[ PHOTO INSERT ]

```

軍人たちと残骸状の物体を写した写真が撮影され、その原版ネガも現在まで保存されています。

**1947年に実際の残骸回収事件があった。**
