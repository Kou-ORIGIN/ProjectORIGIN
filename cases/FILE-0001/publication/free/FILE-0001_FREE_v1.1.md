# 事件概要

1947年、アメリカ・ニューメキシコ州ロズウェル近郊で、牧場主が奇妙な残骸を発見し、米軍は一度「空飛ぶ円盤を回収した」と発表したが、その後、気球とレーダー反射板だったと説明した。

数十年後には「墜落した宇宙船」「回収された宇宙人」「軍による隠蔽」といった説と結びつき、現在まで議論が続いている。

---

# 何が確認されている？

- 1947年7月、ロズウェルの米軍基地が「空飛ぶ円盤を回収した」と実際に発表した。
- 牧場主マック・ブラゼルは、薄い金属状の物、ゴム、棒などの残骸を発見したと当時の新聞に証言している。
- 米軍はその後、回収物を気球とレーダー反射板として説明した。
- 事件当時に撮影された写真や、米軍・FBIなどの公文書が現在も残っている。

---

# なぜ今も謎なのか？

なぜ米軍は最初に「空飛ぶ円盤」と発表したのか。

回収された残骸は、本当に後に説明された気球だったのか。

そして数十年後に現れた「宇宙船」や「宇宙人の遺体」に関する証言は、1947年の事件と本当に結びつくのか。

こうした点をめぐって、現在まで議論が続いている。

---

# 主な説

## 極秘気球説

ソ連の核実験を探知するために行われていた、米軍の極秘気球計画「プロジェクト・モーグル」の残骸だったという説がある。

## 宇宙船墜落説

地球外から来た宇宙船が墜落し、米軍がその残骸を回収したという説がある。

## 隠蔽説

米軍が本当の回収物を隠すため、気球だったと発表したという説がある。

### 現在の位置づけ

証拠の強さは、3つの説で同じではない。

現在もっとも強く支持されているのは極秘気球説だが、特定の気球飛行とロズウェルの残骸が直接結びついたわけではない。

宇宙船墜落説と隠蔽説には、未確認の部分が多く残っている。

---

# 次の調査へ

なぜ極秘気球説がもっとも支持されているのか。

宇宙船や遺体をめぐる証言は、どこまで信用できるのか。

軍の説明変更や失われた記録は、本当に隠蔽を示しているのか。

証言、写真、公文書、残骸、記録の欠落、各説の根拠と問題点はCLASSIFIEDで調査する。
